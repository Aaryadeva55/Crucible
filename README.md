# Crucible

> Forge Better Developers.

Crucible is a coding platform where developers can solve programming challenges, track their progress, compete with others, and receive AI-powered guidance.

This project is also my journey to learning production-ready backend technologies such as Redis, Docker, WebSockets, and AI integration while building a real-world application.

## Tech Stack

- React
- Express
- MongoDB
- Node.js
